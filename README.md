# 🎵 Longevity Hearing

A sophisticated hearing health and auditory exercise platform using medical-grade pure-tone audiometry and AI-powered personalized training.

---

## ✨ Features

- **Medical-Grade Hearing Assessment** – Adaptive frequency-based hearing tests (125Hz–16kHz) detecting hearing loss patterns
- **Audiogram Visualization** – Clinical-grade chart showing hearing thresholds across frequencies
- **AI-Powered Training Plans** – Personalized auditory exercises generated by Google Gemini API
- **Environmental Analysis** – Real-time audio environment monitoring with noise verification
- **Multi-Ear Testing** – Support for left, right, and both-ear assessments
- **Historical Tracking** – Store and compare previous hearing test results
- **Mobile-First Design** – Optimized for mobile devices with responsive interface
- **Accessibility-First** – Built with Radix UI components and semantic HTML

## 🚀 Quick Start

### Prerequisites
- **Node.js** 18+
- **npm** or **yarn**
- **Gemini API Key** (get one at [Google AI Studio](https://aistudio.google.com))

### Installation & Setup

1. **Clone and install dependencies:**
   ```bash
   npm install
   ```

2. **Create `.env.local` and add your Gemini API key:**
   ```
   GEMINI_API_KEY=your_api_key_here
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The app will run at `http://localhost:3000`

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview the production build:**
   ```bash
   npm run preview
   ```

### Other Commands
```bash
npm lint           # Type check without emitting
npm run clean      # Remove dist/ directory
```

## 🏗 Architecture

### Hearing Test Flow (8-Step Wizard)

1. **Intro** – Welcome & instructions
2. **Safety** – Medical disclaimer & contraindication check
3. **Demographics** – Age/sex collection for personalization
4. **Noise Check** – Verify ambient noise levels
5. **Calibration** – Device volume calibration with reference tones
6. **Side Prep** – Select ear(s) for testing
7. **Testing** – Adaptive threshold finding across frequencies
8. **Results** – Display audiogram & AI-generated training plan

### Frequency Testing Order
`[1000, 4000, 500, 8000, 2000, 250, 12000, 125, 16000]`
(Anchor frequencies first, then detail, then extremes)

### Audio Processing
- **Web Audio API** manages tone generation and playback
- Frequency range: 125Hz–16,000Hz
- Sound pressure range: 0–80 dB
- Left/right/both ear configuration

### AI Integration
- **Gemini API** generates personalized training regimens
- Input: Hearing test results + demographics
- Output: Structured auditory training plan

## 🔬 Hearing Loss Thresholds

| Category | Threshold |
|----------|-----------|
| Normal | 0–20 dB |
| Mild Loss | 20–40 dB |
| Moderate Loss | 40–60 dB |
| Severe Loss | 60–80 dB |

**Note:** 8000Hz is critical for detecting high-frequency hearing loss.
