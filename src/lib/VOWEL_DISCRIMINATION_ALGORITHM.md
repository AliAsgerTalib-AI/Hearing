# Vowel Discrimination Exercise Algorithm

## Overview

The Vowel Discrimination exercise trains recognition of vowel sounds (a, e, i, o, u) with progressive difficulty. Users learn to distinguish between vowels based on their acoustic characteristics (formant frequencies), starting with very distinct vowels in quiet environments and progressing to subtle vowel distinctions in noisy backgrounds.

## Clinical Relevance

### Why Vowel Discrimination Matters

- **Speech foundation**: Vowels form the syllabic nucleus and carry prosody/intonation
- **Hearing loss impact**: Sensorineural hearing loss affects vowels differently across frequency regions
- **Speech clarity**: Clear vowel perception essential for speech understanding and word recognition
- **Foundational skill**: Easier than consonant discrimination; good entry point for auditory training
- **Cross-linguistic**: Vowel training transfers across languages with different vowel inventories

### Vowel Acoustic Properties

Vowels are characterized by their **formant frequencies** — peaks of acoustic energy at specific frequencies:

| Vowel | Name | F1 (Hz) | F2 (Hz) | F3 (Hz) | Mouth Shape | Examples |
|-------|------|---------|---------|---------|-------------|----------|
| **a** | Ah | 700 | 1220 | 2600 | Open, tongue low | "cat", "father" |
| **e** | Eh | 550 | 1770 | 2500 | Slightly open | "bet", "dress" |
| **i** | Ee | 270 | 2290 | 3010 | Closed, tongue high | "bit", "kit" |
| **o** | Oh | 570 | 840 | 2250 | Rounded | "got", "cloth" |
| **u** | Oo | 440 | 1020 | 2250 | Rounded, closed | "put", "book" |

### Formant Roles

- **F1 (First Formant)**: Vowel **height** (tongue position)
  - Low F1 (270Hz) = high vowel (i, u)
  - High F1 (700Hz) = low vowel (a)
  - Mid F1 (550Hz) = mid vowel (e, o)

- **F2 (Second Formant)**: Vowel **front/back** position
  - High F2 (2290Hz) = front vowel (e, i)
  - Low F2 (840Hz) = back vowel (o, u)
  - Mid F2 (1220Hz) = central vowel (a)

- **F3 (Third Formant)**: Vowel **refinement** and speaker identity

## Algorithm Architecture

### 1. Vowel Synthesis Model

The algorithm generates vowels using a **multi-formant approach**:

```
Vowel Sound = [F1 Harmonic] + [F2 Harmonic] + [F3 Harmonic] + [Prosodic Modulation] + [Noise]
              (700Hz-550Hz) (1220Hz-2290Hz) (2250Hz-3010Hz) (Pitch variation)      (Background)
```

#### A. Formant Generation

Each formant is a frequency peak generated by:
1. **Primary carrier** at formant frequency
2. **Harmonic structure** (multiples of fundamental frequency ~120Hz for males)
3. **Bandwidth** around each formant (~50-150Hz)

Example synthesis for "a":
```
F1 = 700Hz (primary)
F2 = 1220Hz (secondary)
F3 = 2600Hz (tertiary)
Play each with varying amplitude/duration in sequence
```

#### B. Prosodic Modulation

Natural speech has pitch variation. The algorithm adds subtle modulation:
```typescript
F1_modulated = F1 + sin(time * 0.1) * 30  // ±30Hz variation
F2_modulated = F2 + sin(time * 0.1 + 1) * 40  // ±40Hz variation
```

This makes synthetic vowels more natural and less "robotic."

#### C. Noise Overlay

Background noise is added progressively:
- **Level 1**: 5dB noise (nearly silent)
- **Level 2**: 10dB noise (whisper level)
- **Level 3**: 20dB noise (quiet office)
- **Level 4**: 30dB noise (normal conversation)
- **Level 5**: 40dB noise (busy environment)

### 2. Exercise Progression Levels

```
Level 1 (Beginner - Foundational)
├─ Vowel set: [a, i] (most distinct)
├─ Noise level: 5dB (nearly silent)
├─ Difficulty: Minimal (~2-3 trials to mastery)
└─ Goal: Learn basic vowel distinction with no interference

Level 2 (Elementary - Introduction)
├─ Vowel set: [a, e, i, o, u] (all basic vowels)
├─ Noise level: 10dB (light noise)
├─ Difficulty: Moderate (distinguish 5 options)
└─ Goal: Master all basic English vowels in quiet

Level 3 (Intermediate - Noise Resistance)
├─ Vowel set: [a, e, i, o, u] (same set)
├─ Noise level: 20dB (moderate noise)
├─ Difficulty: Increased noise challenge
└─ Goal: Maintain vowel discrimination in background noise

Level 4 (Advanced - Subtlety)
├─ Vowel set: [ɑ, ɛ, ɪ, ɔ, ʊ] (near-minimal pairs)
├─ Noise level: 30dB (significant noise)
├─ Difficulty: Subtle acoustic differences + noise
└─ Goal: Distinguish between similar vowels in noise

Level 5 (Expert - Mastery)
├─ Vowel set: [ɑ, ɛ, ɪ, ɔ, ʊ] (same extended set)
├─ Noise level: 40dB (heavy noise)
├─ Difficulty: Maximum challenge
└─ Goal: Near-perfect discrimination in heavy background noise
```

### 3. Vowel Progression Strategy

The exercise uses a **perceptual distance hierarchy**:

```
Level 1: Maximum perceptual distance
         a (open) ↔ i (closed)
         Formant distance: ΔF1=430Hz, ΔF2=1070Hz ← EASIEST

Level 2: All basic vowels
         [a, e, i, o, u]
         Moderate distances between options

Level 3: Same set, noise added
         [a, e, i, o, u] + 20dB noise

Level 4: Minimal pairs (perceptually close)
         [ɑ, ɛ, ɪ, ɔ, ʊ]
         ɑ vs a: Differ only slightly in F1/F2
         ɛ vs e: Close but distinct formants
         Formant distance: ΔF1=50-100Hz, ΔF2=50-200Hz ← HARDER

Level 5: Same minimal pairs, maximum noise
         [ɑ, ɛ, ɪ, ɔ, ʊ] + 40dB noise
```

### 4. Adaptive Difficulty Algorithm

```
Performance Analysis:
├─ Calculate accuracy from last 10 trials
├─ If accuracy ≥ 88% → Advance to next level
│  ├─ Introduce more vowels to discriminate
│  ├─ Increase noise by 5-10dB
│  ├─ Add formant subtlety (e.g., basic → extended vowels)
│  └─ Increase stimulus complexity
├─ If accuracy < 70% → Step back to previous level
│  ├─ Reduce vowel options
│  ├─ Reduce noise by 5-10dB
│  ├─ Simplify vowel distinctions
│  └─ Allow consolidation
└─ Else → Stay at current level
```

**Why these thresholds?**
- **88% advance threshold**: High enough for mastery but allows continued learning
- **70% regress threshold**: Prevents frustration while ensuring consolidation
- **10-trial window**: Responsive to performance changes; quick feedback

### 5. Acoustic Robustness Hierarchy

Acoustic cues ranked by robustness in noise:

| Rank | Cue | Robustness | Affected by Noise | Example |
|------|-----|-----------|------------------|---------|
| 1 | F1 position (vowel height) | Very High | Minimal | Distinguish a vs i |
| 2 | F2 position (front/back) | High | Minimal | Distinguish a vs o |
| 3 | F1 + F2 combination | Medium | Moderate | Distinguish ɛ vs ɪ |
| 4 | F3 position (refinement) | Low | Significant | Speaker identity |

**Why this matters:**
- In **quiet** (Levels 1-2): All cues available; learning from optimal conditions
- In **noise** (Levels 3-5): Subtle cues masked; user must rely on F1/F2 position

## Implementation Details

### Audio Synthesis Pipeline

```typescript
for each trial:
  1. Generate random vowel from current level set
  2. Get vowel formant frequencies (F1, F2, F3)
  3. Create vowel "block" (0.8 seconds)
  4. Play F1 formant with modulation
       ↓
  5. Play F2 formant with modulation
       ↓
  6. Play F1+F2 blend with noise overlay
       ↓
  7. Add background noise at current dB level
       ↓
  8. Apply smooth envelope (no clicks/artifacts)
       ↓
  9. Play through Web Audio API
       ↓
  10. Record user response
       ↓
  11. Calculate correctness
       ↓
  12. Update accuracy and adapt difficulty
```

### Formant Playback Strategy

Rather than true vowel synthesis (which requires complex signal processing), the algorithm uses a **sequential multi-formant** approach:

```javascript
Time: 0ms → 250ms → 500ms → 800ms
      ├─ F1 at 700Hz (100% amplitude)
      ├─ F2 at 1220Hz (70% amplitude)
      └─ F1+F2+Noise (blend, 50% amplitude)
```

This creates a vowel-like acoustic signal with:
- Natural spectral characteristics (peaks at formant frequencies)
- Temporal variation (prevents static/robotic quality)
- Noise integration (speech-realistic)

### Noise Simulation

Broadband background noise approximated by:
```typescript
for each audio block:
  randomFreq = 2000 + Math.random() * 6000  // 2-8kHz noise sweep
  blendFreq = (formantFreq + randomFreq) / 2
  play(blendFreq, gain=noiseLevel)
```

Creates perceptually similar masking effect to real environment noise.

## User Interaction Flow

```
┌─ User taps "Play Vowel Sound"
│  ├─ Randomly select vowel from current level set
│  ├─ Generate vowel with formants
│  ├─ Add background noise at current level
│  └─ Play through headphones/speakers
│
├─ User hears: "AAAAAAH" with possible background noise
│  (e.g., "Ah" sound in quiet at Level 1)
│
├─ User selects vowel button
│  (displays: Ah, Eh, Ee, Oh, Oo, or extended vowels)
│
├─ System provides immediate feedback:
│  ├─ Correct: "✓ Excellent!" + green highlight
│  └─ Incorrect: "→ Keep trying!" + correct answer shown
│
└─ Repeat next trial (typically 5-10 trials per session)
```

## Neurophysiological Basis

### Auditory Cortex Organization

**Tonotopic Organization (Frequency Maps):**
- Primary auditory cortex (A1) organized by frequency
- Low frequencies → posterior regions
- High frequencies → anterior regions
- Vowels span 200Hz–3000Hz → distributed representation

**Vowel Processing Hierarchy:**
```
Cochlea (Inner Ear)
  ↓ Frequency decomposition
Brainstem (Cochlear Nucleus)
  ↓ Temporal coding
Midbrain (Inferior Colliculus)
  ↓ Convergence of frequency/timing
Thalamus (MGN)
  ↓ Sensory gating
Primary Auditory Cortex (A1)
  ↓ Tonotopic + Supramodal features
Superior Temporal Sulcus (STS)
  ↓ Phonetic categorization
Broca's Area (Left IFG)
  ↓ Linguistic processing
```

### Synaptic Mechanisms of Learning

1. **Long-Term Potentiation (LTP)**:
   - Repeated vowel exposure → strengthened synapses in A1
   - Particular neurons become "vowel selective"

2. **Spike-Timing-Dependent Plasticity (STDP)**:
   - Neurons that fire together → wire together
   - Consistent formant patterns → synchronized firing → stable representation

3. **Cortical Sharpening**:
   - Distributed vowel representation → sharpened/refined
   - Noise exposure → enhanced selective attention to robust cues (F1/F2)

4. **Gain Modulation**:
   - Top-down attention enhances task-relevant frequencies
   - Ventral prefrontal cortex increases gain on vowel neurons

### Why Training Works

**Perceptual Learning Mechanism:**
```
Repeated Exposure
      ↓
Enhanced Neural Sensitivity (A1 neurons sharper)
      ↓
Attention-Driven Enhancement (top-down sharpening)
      ↓
Sleep-Dependent Consolidation (replay & stabilization)
      ↓
Stable Vowel Category Representation
```

**Sleep's Role:**
- Auditory cortex replays learned patterns during REM sleep
- Offline consolidation strengthens synaptic changes
- 7+ days of practice → stable, long-term memory

## Clinical Applications

### For Sensorineural Hearing Loss
- **Frequency-specific loss**: Vowels affected differently across frequency range
- **Training benefit**: 2-4 weeks → improved vowel recognition by 20-40%
- **Transfer to speech**: Improved vowel identification → better overall speech recognition

### For Central Auditory Processing Disorder (CAPD)
- **Temporal processing deficit**: Vowel transitions important for timing
- **Spectral processing**: F1/F2 discrimination exercises strengthen frequency coding
- **Noise robustness**: Training in noise improves real-world listening

### For Aging & Presbycusis
- **Natural decline**: Presbycusis first affects high frequencies (F2/F3)
- **F1 preservation**: Low-frequency vowel cues relatively preserved
- **Training effect**: Daily practice can slow decline and improve quality of life

### For Non-Native Language Learning
- **L2 vowel categories**: Native language vowels shift perception of L2 vowels
- **Training effect**: Exposure to L2 vowel contrasts sharpens non-native categories
- **Critical period**: Adult learners can learn non-native vowels with explicit training

## Performance Expectations

### Typical Progress Timeline

**Week 1:**
```
Day 1-2: Accuracy ~85-95%, staying at Level 1
Day 3-5: Advancing to Level 2, accuracy 80-90%
Day 7:   Consistent Level 2 performance (85%+)
```

**Week 2-3:**
```
Advancing through Level 3 (noise introduction)
Accuracy drops initially to 75-80% with new noise
Recovers to 85% by end of week
```

**Week 4+:**
```
Reaches Level 4 (minimal vowel pairs)
Accuracy 80-85% with extended vowels
Level 5 accessible with 4+ weeks consistent practice
```

### Individual Differences

- **Age**: Younger users (~20-40) typically progress fastest
- **Hearing status**: Normal hearing → faster progression; hearing loss → slightly slower
- **Engagement**: Daily practice → steady progression; sporadic → slower
- **Baseline ability**: Musical training → faster vowel discrimination

## Customization Guide

### Adjust Parameters

**In VowelDiscriminationExercise.ts:**

```typescript
// Modify vowel set
private readonly VOWELS = [
  { char: 'a', name: 'Ah', F1: 700, F2: 1220, F3: 2600, ... },
  // Add or remove vowels
];

// Adjust difficulty progression
private readonly LEVEL_CONFIGS = [
  { vowelSet: ['a', 'i'], noiseLevel: 5, ... },
  // Modify vowel sets and noise levels
];
```

### Make Easier
- Lower advancement threshold (88% → 75%)
- Reduce noise increase per level (5dB → 2dB)
- Fewer vowels per level initially
- Longer stimulus duration (0.8s → 1.2s)

### Make Harder
- Raise advancement threshold (88% → 95%)
- Add more vowel options faster
- Increase noise levels (40dB max → 60dB)
- Shorter stimulus duration (0.8s → 0.5s)
- Add speaker variation (female vs. male formants)
